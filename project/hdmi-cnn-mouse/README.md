# HDMI · CNN · Mouse 学习记录

这个目录按版本保存 RK3588 图像识别与鼠标控制项目的程序和实验。不同版本的用途不同，不是直接替换权重就能互相运行。

| 版本 | 内容 | 状态 |
| --- | --- | --- |
| [v1](v1/README.md) | HDMI 视频输入、YOLO NPU 检测、侧键开关和鼠标控制 | 第一版板端程序与权重归档 |
| [v2](v2/README.md) | YOLO26n 四种分辨率训练、电脑 PT 测速、320×192 RKNN 转换 | 分辨率实验归档，历史转换使用 Toolkit2 2.3.2 |
| [v3](v3/README.md) | RKNN 2.5 板端多核调度、内存处理实验，以及新增 640×640 YOLO26n 训练与测试 | 2026-11-13 实测归档；没有接管 v1 的 HDMI/鼠标流程 |

要看最新的 NPU 吞吐量与延迟对比，直接阅读 **[v3 README](v3/README.md)**。v3 同时保留原始采样、模型和复现代码；其中的并发 FPS 不等于 HDMI 实时帧率或鼠标响应延迟。
